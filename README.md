# 📊 Dashboard Logístico | Looker Studio

## 📖 Sobre o projeto

Este projeto apresenta um dashboard desenvolvido no Google Looker Studio com o objetivo de analisar indicadores logísticos e apoiar a tomada de decisão por meio da visualização de dados.

O painel reúne métricas relacionadas ao desempenho das entregas, custos, fretes e atrasos, permitindo identificar padrões operacionais, acompanhar indicadores e gerar insights para otimização dos processos logísticos.

---

## 🎯 Objetivos

- Monitorar indicadores logísticos.
- Identificar padrões de atraso nas entregas.
- Comparar desempenho entre períodos.
- Analisar custos de frete e impacto financeiro.
- Apoiar decisões estratégicas através da visualização de dados.

---

## 🛠️ Ferramentas utilizadas

- Google Looker Studio
- Google Sheets
- Data Visualization
- Data Storytelling

---

## 📈 Indicadores analisados

- Total de Entregas
- Pedidos em Atraso
- Taxa de Atraso
- Valor Total de Frete
- Tempo Médio de Entrega
- Indicadores por período
- Análises comparativas

---

## 💡 Principais insights

O dashboard permite identificar tendências nos atrasos das entregas, acompanhar indicadores operacionais e visualizar oportunidades de melhoria nos processos logísticos, facilitando uma tomada de decisão baseada em dados.
